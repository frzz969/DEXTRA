# DEXTRA — Known Limitations

1. Telegram adapter hanya skeleton (bukan MVP).
2. Customer Operations spesialis = roadmap, bukan agent aktif.
3. Integrasi email/kalender nyata = mock (tidak ada data nyata pelanggan).
4. Autentikasi multi-pengguna sungguhan tidak ada (MVP simulasi sesi).
5. D-03 (ops token di browser) belum full server-side proxy.
6. Precedent retrieval bersifat opsional (PRD v1.4.0 §19.4; penomoran v2 berbeda).
7. LLM/ASR bahasa Indonesia tidak dijamin (jalur transkripsi sebagai input).
8. Retensi data MVP (30/90/180 hari) adalah keputusan MVP, bukan kewajiban regulasi.
9. Klaim sertifikasi keamanan tidak diajukan.
